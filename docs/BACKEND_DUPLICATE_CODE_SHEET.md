# Backend Duplicate-Code Sheet

> **Scope:** every PHP file under `app/` (120 controllers, 17 services, 36 support classes, 112 models, 21 mailables, jobs, commands, middleware) plus `routes/api.php`, `web.php` and `console.php`.
> **Method:** a read-only audit of each domain. Every copy listed was opened and compared. **No code was changed.**
> **Date:** 2026-10-26 · branch `saas`
>
> **Legend**
> - **Similarity:** *Identical* = same apart from names. *Near* = same structure with small differences.
> - **DRIFT** = the copies have already diverged, so the duplication is causing a real behaviour difference or bug.
> - Paths are relative to `app/`. `Api/` = `Http/Controllers/Api/`.
> - Line ranges are `start-end` as of this date. They will move as code changes.
