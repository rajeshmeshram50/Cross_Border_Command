- **Comments**: removed with PHP's own tokenizer (`token_get_all`), so only real comment tokens were removed — strings, heredocs, SQL and `#[Attributes]` were not touched.

- **Dead code**: script listed private methods / properties / constants never referenced in their own class, and classes whose name appears nowhere else in the project (routes, config, app, database, views, tests, frontend). Each candidate was then checked by hand.
