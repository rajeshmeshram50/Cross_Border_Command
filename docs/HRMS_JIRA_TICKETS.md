# HRMS — Bug Tickets

- **Attendance** — Future dates show "Absent" before the day has even happened. They should stay blank until the date arrives.

- **Payroll** — Professional Tax is the same for everyone (Maharashtra rate). It should change based on the employee's work state.

- **Leave** — If a leave type is not marked Paid or Unpaid, the system treats it as Paid, so no salary is cut. It should not assume Paid by default.

- **Holiday** — A holiday that falls on an employee's weekly off is still counted as a paid holiday. It should not be paid twice.
