## How the pieces connect

```
  Authority ──▶ KYC · DD · QC · Trade Licences        (the catalogues)
                          │
  Segment ────────────────┼──▶ DOCUMENT CONTROL PANEL  (the rule:
                          │      segment × domestic|international → M/O docs)
                          │
                          ├──▶ Party forms  ──▶ Evidence Vault (uploads)
                          │
  Clause Library ─┐       └──▶ Customer Profile · Supplier Profile
  T&C Library    ─┼──▶ Trade Documents · Agreements ──┐   (the X-of-Y scorecards)
  Agreement Types─┘                                    │
                                                       ├──▶ E-SIGNATURE (Zoho Sign)
  Case to Case ──▶ Agreements We Sent ─────────────────┘         │
               └─▶ Agreements To Approve                          ▼
                                                    signed PDF + certificate
                                                              │
                          Analytics · Diagnosis & Resolution · Regulatory Defense File
```
